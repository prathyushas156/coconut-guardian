# Assets (screenshots & demo)

Put your README media files in this folder.

## Expected filenames

- `banner.png` (recommended size: 1280×640 or similar wide banner)
- `screenshot-home.png` (the upload page)
- `screenshot-result.png` (prediction + confidence + heatmap if available)
- `demo.mp4` (optional; alternatively use a YouTube link in the main README)

## How to capture screenshots (quick)

### Windows

- Press `Win + Shift + S` to snip and save as PNG.

## Demo video options

- **Best**: upload to YouTube and paste the link into `README.md`.
- **OK**: attach an `.mp4` to a GitHub Release and link it from `README.md`.
- **Not recommended**: committing a large `.mp4` directly into the repo (GitHub size limits / clone bloat).
